# Ateliê da Dani

Site institucional para o Ateliê da Dani, confeitaria artesanal especializada em brigadeiros e doces personalizados.

🔗 **Site no ar:** https://atelinedadani.netlify.app/

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Swiper e AOS (carrossel e animações)

## Recursos
- Catálogo de produtos e preços
- Galeria de fotos
- Avaliações de clientes
- Integração com WhatsApp e Instagram
